# Project Context

## Objetivo

ServiceDesk es una plataforma SaaS de gestión de incidencias y soporte técnico para empresas.

El proyecto busca combinar aprendizaje con una implementación de calidad profesional y una estructura similar a una aplicación empresarial real.

## Áreas de aprendizaje

- ASP.NET Core
- Entity Framework Core
- SQL Server
- Azure
- Clean Architecture
- Buenas prácticas
- CI/CD
- Testing

## Criterio general

Las decisiones deben favorecer mantenibilidad, claridad y evolución futura sin introducir complejidad innecesaria.
