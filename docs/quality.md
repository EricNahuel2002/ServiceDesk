# Quality

Siempre que sea posible:

- Validar entradas.
- Manejar errores.
- Registrar logs.
- Mantener código desacoplado.
- Pensar en escalabilidad.
- Escribir tests apropiados.

## Testing

Framework previsto:
- xUnit

Los tests deben acompañar funcionalidades relevantes y evitar convertirse en una excusa para introducir complejidad innecesaria.

## Base de datos

- Entity Framework Core.
- Migraciones mediante EF Core.
- Procedimientos almacenados solo con una razón clara.
