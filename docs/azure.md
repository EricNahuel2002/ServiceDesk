# Azure Roadmap

Los servicios de Azure se incorporarán progresivamente.

Orden recomendado:
1. Azure SQL Database
2. Azure App Service
3. Azure Blob Storage
4. Application Insights
5. Azure Key Vault
6. Azure Queue Storage
7. Azure Functions

## Principios

- Preferir servicios administrados antes que máquinas virtuales.
- Mantener la lógica de negocio independiente de Azure.
- Las integraciones con Azure pertenecen a Infrastructure.
- No incorporar un servicio antes de que exista una necesidad concreta.
